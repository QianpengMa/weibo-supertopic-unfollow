# weibo-supertopic-unfollow

微博超话批量取关工具，在电脑浏览器控制台运行，支持勾选取关、保留名单和停止处理。

A browser console script for bulk unfollowing Weibo Super Topics, with selective unfollowing, a keep list, and a stop button.

## 使用前须知

- **仅用于操作本人账号的已关注超话列表。** 运行前请阅读并检查脚本代码，确认理解它会执行的操作；不要在控制台运行来源不明的代码。
- **建议首次只测试一个超话**，确认取关结果正确后再批量操作。
- **已完成的取关无法通过脚本自动恢复。**「停止」只阻止继续处理，已经发出的当前操作仍可能完成；「关闭」也不会撤销取关。
- 工具只识别当前页面已加载、能够识别的超话，**不会自动翻页或加载全部关注列表**。微博页面变化可能导致识别失败，不保证适配所有页面。
- 运行期间请勿操作微博页面或切换页面地址。完成或停止后，请刷新微博复核结果。

## 下载脚本

1. 打开 [weibo_supertopic_unfollow.js](./weibo_supertopic_unfollow.js)。
2. 点击 GitHub 文件页面的 **Raw** 查看原始代码，复制完整内容；也可以下载原始文件后，用记事本或其他文本编辑器打开并全选复制。
3. **不要双击运行 `.js` 文件**，也不要把代码粘贴到浏览器地址栏。它需要在微博网页的开发者工具控制台中运行。

## 在浏览器中运行

1. 用电脑浏览器打开 [微博](https://weibo.com/)，登录本人账号，进入「我的关注」中的「超话」列表，确认页面显示的是自己已关注的超话。
2. 先向下滚动，让准备处理的超话加载出来。
3. 保持在该微博页面，打开开发者工具的 **Console / 控制台**。Chrome 等浏览器通常可使用：
   - Windows：`Ctrl + Shift + J`
   - macOS：`Command + Option + J`
   - 若快捷键不适用，可从浏览器菜单打开开发者工具，再切换到 Console。
4. 检查代码后，将**完整脚本**粘贴到控制台输入区，按回车执行。
5. 网页右上角出现「微博超话批量取关 · 快速版」浮窗，表示工具已打开。脚本启动时会扫描一次页面，**此时不会开始取关**。

如果控制台阻止粘贴，请先确认代码可信，再阅读浏览器自己的提示，并仅按提示手动输入允许粘贴的短语（例如 `allow pasting` 或「允许粘贴」）。以实际提示为准，不要输入 `Plain text` 或 `JavaScript`。

## 扫描、保留与取关

1. 点击「扫描当前页」，核对识别出的超话名称。扫描本身不会改变关注状态。
2. 在「保留名单」填写不想取关的**超话名称或 ID，一行一个**；可以留空。名称尽量与扫描结果一致。匹配到的项目会标注「保留」，无法勾选。
3. **首次只勾选一个**确定要取关的超话，点击「取关所选」，等待处理结果，再刷新微博确认。
4. 测试无误后，按需继续滚动加载、重新扫描，填写保留名单并勾选其他项目。也可点击「全选」，但应先逐项核对名单，再点击「取关所选」。
5. 等待任务完成，刷新微博复核。新加载的项目需要重新扫描后再执行。

| 控件 | 作用 |
| --- | --- |
| 扫描当前页 | 识别页面已加载且可识别的已关注超话；不会取关。重新扫描可能保留之前的勾选，请核对。 |
| 保留名单 | 按名称或 ID 排除不想取关的超话，一行一个。 |
| 超话前的复选框 | 勾选表示本次要取关；不勾选则不处理。 |
| 全选 | 勾选扫描结果中未被保留名单排除的项目。 |
| 清空选择 | 取消全部勾选，不改变微博关注状态。 |
| 取关所选 | 依次处理已勾选且未被保留名单排除的超话。 |
| 停止 | 请求停止后续处理；已经发出的操作仍可能完成，已取关项目不会自动恢复。 |
| 关闭 | 空闲时关闭浮窗；任务运行中会先请求停止，停止后可再次点击关闭。 |
| 底部提示 | 显示识别数量、处理进度，以及停止或异常原因。 |

## 未识别或中途停止时

- **扫描结果为 0：**确认位于本人已关注超话列表，向下滚动加载后重新扫描；仍为 0 时，可能需要适配实际页面。
- **出现验证、操作频繁或其他异常：**脚本检测到相关提示会停止。请查看微博页面，处理提示并刷新复核，不要反复强行执行。
- **无法定位目标、结果不明确或页面地址改变：**任务会停止。先检查实际关注状态，再重新扫描、核对和选择。
- **刷新页面后浮窗消失：**需要在正确页面重新运行脚本，并重新填写保留名单。
